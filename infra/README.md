# infra/

| File | Purpose |
|---|---|
| `backend.hcl` | Remote state location — **generated by bootstrap**, commit it |
| `bootstrap.auto.tfvars` | Lab RG + SQL admin group — **generated by bootstrap**, commit it |
| `versions.tf` | Terraform/provider pins, backend, provider config |
| `variables.tf` | Inputs |
| `main.tf` | Lab RG lookup, naming suffix, tags |
| `sql.tf` | SQL server (Entra-only), firewall, free-offer database |
| `web.tf` | Static Web App (Free) |
| `api.tf` | App Service plan (F1) + .NET web app (managed identity) |
| `outputs.tf` | Values consumed by the pipeline |

Local run:
```bash
export ARM_SUBSCRIPTION_ID=$(az account show --query id -o tsv)
terraform init -backend-config=backend.hcl
terraform plan
```
